CONFIGURACIÓN DEL FORMULARIO DE CONSULTAS
==========================================

La web ya quedó preparada para:

1. Recibir el formulario en contacto.php.
2. Enviar la consulta a Atención al Socio.
3. Enviar automáticamente al usuario el mensaje:
   “¡Recibimos tu consulta! Gracias por comunicarte con nosotros. Recibimos correctamente tu mensaje y te responderemos a la brevedad.”
4. Si se configura OPENAI_API_KEY, la IA lee la consulta y manda una respuesta automática personalizada.
5. El correo lleva la gráfica de Talleres como cabecera y un pie institucional.

IMPORTANTE
----------
El ZIP NO contiene ninguna clave secreta de OpenAI. La API key debe configurarse en el servidor como variable de entorno.

VARIABLES RECOMENDADAS
----------------------
OPENAI_API_KEY = tu clave de API
OPENAI_MODEL   = gpt-5-mini
ADMIN_EMAIL    = socios@clubtalleres.com.ar
MAIL_FROM      = socios@clubtalleres.com.ar
SITE_URL       = https://TU-DOMINIO.com.ar

Si el hosting no permite variables de entorno, se puede colocar la clave directamente en config.php, pero NO se recomienda subir una clave real a un repositorio público.

CORREO
------
El envío usa la función mail() de PHP. El hosting debe tener el servicio de correo PHP habilitado.
Si el proveedor usa SMTP obligatorio, habrá que conectar PHPMailer/SMTP con las credenciales del dominio.

IA
--
La IA responde solamente con la información institucional incluida en contacto.php. Si no encuentra información suficiente, indica que Atención al Socio debe revisar la consulta, evitando inventar datos.

Para probarlo, subir la carpeta completa a un servidor con PHP y enviar una consulta desde el formulario de Socios.
